# Algorithm Tracker

我的个人 Codeforces 算法训练记录系统。

## Features

- Codeforces 用户信息同步
- Codeforces 刷题记录同步
- Rating 分类
- 题目标签统计
- 错题记录
- 错误次数统计
- AC 次数统计
- 错误率分析
- 训练重点分析
- LocalStorage 本地数据保存
- 一个 Codeforces ID 对应独立题库

## Tech Stack

- HTML
- CSS
- JavaScript
- Codeforces API
- LocalStorage
